# Gato Rumano Static

Sitio estático del restaurante El Gato Rumano, listo para desplegar en S3 manteniendo el estilo original y eliminando la parte dinámica/PHP.

Estructura:
- `index.html`: home page
- `pages/productes.html`: catálogo de productos
- `pages/contacte.html`: información de contacto
- `pages/copyright.html`: aviso legal
- `styles.css`: estilos del sitio
- `data/products.json`: catálogo de productos en formato JSON
- `script/*.js`: comportamiento de carrusel, tema oscuro y catálogo
